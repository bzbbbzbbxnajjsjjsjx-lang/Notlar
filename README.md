# Notlar

Material 3 Expressive (Jetpack Compose) not ve yapılacaklar uygulaması.

- **Notlar**: İki sütunlu kartlar, sabitlenenler üstte. Arama ve *Tümü / Notlar / Yapılacaklar* süzgeçleri.
- **Yazma ekranı**: Otomatik kayıt; yüzen araç çubuğunda yapılacak listesine çevirme, renk, arşivleme, paylaşma ve silme.
- **Arşiv**: Ana listeden kaldırılan notlar.
- **Çöp kutusu**: Silinen notlar 30 gün saklanır; geri yükleme, kalıcı silme, çöpü boşaltma.
- **Ayarlar**: Tema (Sistem / Açık / Koyu), duvar kağıdından dinamik renkler (Android 12+), sıralama, JSON yedeği dışa ve içe aktarma.
- **Ek özellikler**: Liste görünümü, uzun basarak toplu seçim, yapılacak ilerlemesi, not kopyalama, başka uygulamalardan paylaşılan metni not olarak kaydetme, ana ekran kısayolları.
